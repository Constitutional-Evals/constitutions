# Foundational documents for `neo-aristotelian-virtue-ethics`

This bundle follows the technical appendix's Neo-Aristotelian virtue ethics
row: G. E. M. Anscombe, "Modern Moral Philosophy" (1958); Philippa Foot,
*Natural Goodness* (2001); Rosalind Hursthouse, *On Virtue Ethics* (1999);
and Alasdair MacIntyre, *After Virtue* (1981).

The appendix's four modern works remain metadata-only, but this is not a
metadata-only bundle. It includes a public-domain translation of Aristotle's
*Nicomachean Ethics*, Books I-II, and a CC BY 4.0 contemporary chapter on
virtue ethics. These provide directly usable source text for the classical and
contemporary sides of the tradition.
